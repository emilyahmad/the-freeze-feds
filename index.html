Be Elsa Ice Magic

A webcam hand-gesture winter scene. Your hands make snow, frost, snowballs, ice towers, aurora and snow buddies.

  • Needs your camera
  • Runs from any static server (this one works)

SF I-Spy

Walk the streets of San Francisco. Every 8 seconds the video freezes and you get 5 seconds to tap what Claude spied.

  • Needs its own Node server: cd sf-i-spy && npm install && ANTHROPIC_API_KEY=… npm start
  • Asks to share the tab so Claude can see each frame

The Freeze Feds

A crowd strolls through California & Powell. Hover to inspect people and click the ten tech and finance bosses to freeze them in ice before time runs out.

  • Needs its own dev server: cd freeze-feds && npm install && npm run dev
  • Mouse or trackpad recommended
